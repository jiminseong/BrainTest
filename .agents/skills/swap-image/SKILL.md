# 이미지 교체하기

사용자가 새 이미지 파일(png, jpg, webp 등)을 주면 기존 이미지와 **같은 파일명·같은 포맷·비슷한 크기**로 바꿔 넣습니다. 코드는 수정하지 않습니다.

1. 어떤 유형(1~16)의 어떤 이미지인지 확인합니다. 모호하면 `AGENTS.md` 표의 종류(뉴런 / 구조 / 로고 / 결과지 / 카톡 미리보기)를 보여주고 고르게 합니다.
2. 현재 브랜치가 `main`이나 `develop`이면 `develop`에서 새 브랜치를 만듭니다. 이름은 `edit/MMDD-내용`.
3. 기존 파일의 가로·세로 크기를 확인합니다. 예: `sips -g pixelWidth -g pixelHeight <파일>` (맥).
4. 새 이미지를 기존과 같은 비율·비슷한 크기로 맞추고 webp로 변환합니다. 변환 도구가 없으면 `npx sharp-cli` 또는 `npx @squoosh/cli`를 사용하되, 설치 전에 사용자에게 한 줄로 알립니다. 비율이 많이 다르면 자르기 전에 사용자에게 확인합니다.
5. 기존 파일을 새 파일로 **덮어씁니다.** 파일명은 절대 바꾸지 않습니다.
6. `npm run build` 통과를 확인합니다.
7. `npm run dev`로 띄우고 브라우저에서 해당 이미지가 나오는 화면을 열어 **직접 확인한 뒤 보여줍니다.**
   - 뉴런·구조·로고: `/test/result/{N}/테스트` (마지막 칸은 아무 이름)
   - 결과지: `/save/{N}/테스트` 또는 `/print/{N}/테스트`
   - 카톡 미리보기(`public/og-image.jpg`): 파일만 확인. 배포 후 카카오 공유 디버거에서 캐시 삭제가 필요하다고 사용자에게 알립니다.
8. 어떤 파일을 바꿨는지 보고하고, 반영하려면 `/publish`를 따릅니다.
