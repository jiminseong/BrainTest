# 문구 바꾸기

사용자는 개발자가 아닐 수 있습니다. 쉬운 말로 진행 상황을 알려주세요.

1. 어떤 문구를 어떻게 바꿀지 확인합니다. 사용자가 "17번 문항"처럼 번호로 말하면 `question.json`의 17번째 문장입니다(1부터 셉니다). 화면 문구면 `AGENTS.md`의 표에서 파일을 찾고, 없으면 `src/pages` 안에서 그 문장을 검색합니다.
2. 현재 브랜치가 `main`이나 `develop`이면 `develop`에서 새 브랜치를 만듭니다. 이름은 `edit/MMDD-내용`.
3. 문장만 바꿉니다. 아래는 그대로 둡니다.
   - `question.json`의 `{{mobileBr}}` 표시, 문항 개수·순서, 따옴표·쉼표 같은 JSON 구조
   - 코드 파일의 태그, 변수, 스타일
   - 채점 관련 파일(`questionMapping.tsx` 등)
4. `npm run build`를 실행해 통과를 확인합니다.
5. `npm run dev`로 사이트를 띄우고 브라우저에서 바뀐 화면을 열어 **직접 확인한 뒤 사용자에게 보여줍니다.** 문항은 `/test/content`에서 해당 번호까지 답을 눌러 진행해야 보입니다. 결과 페이지 문구는 `/test/result/{N}/테스트`로 바로 열 수 있습니다.
6. 무엇을 어디서 바꿨는지 한두 문장으로 보고하고, 바로 반영할지 물어봅니다. 반영하려면 `/publish`를 따릅니다.
